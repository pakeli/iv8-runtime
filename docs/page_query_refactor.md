# Page refactor — query-parameter codec

Scope agreed: `2026-11-04`. Status: **VERIFIED on real V8 — Linux x64,
Windows x64, macOS arm64 (`2026-11-04`)**.
Baseline: `a9b550c` (verified URL parser extraction, PR #3).

Extract byte-level query parsing/serialization and form-URL encoding from
`page_state.cpp` into a V8-independent `query_parameters` module. Preserve
ordered duplicate pairs, empty names/values, malformed percent escapes, `+`
decoding, explicit ASCII encoding, and uppercase percent hex. The constructor
still removes its leading `?` before invoking the parser.

Keep the canonical string in the existing GC-managed V8 private slot. JS
coercion, method mutation, private keys, constructor validation, and the
non-live `URL.searchParams` snapshot stay in the host layer. No new native
back-pointer, ownership transition, Python/JS API, iterator, or browser feature.
M11-53 remains the next feature milestone.

## Verification plan

Compare old/new parsed pairs and serialized strings across explicit and
generated byte inputs, including every byte value, under UBSan. Add Python
regressions for malformed escapes, literal/encoded plus, empty/duplicate keys,
NUL/Unicode, and copy/snapshot mutation. Run focused query/URL consumer tests,
then real-V8 CI and Linux/Windows/macOS arm64 release matrices. Record actual
source trees, run IDs, artifacts, and test counts before marking verified.

## Local results — `2026-11-04`

- Added `include/iv8/query_parameters.h` / `src/core/query_parameters.cpp` and
  registered the new translation unit in CMake. Host callbacks now call the
  shared pair parser/serializer; their private-slot state and mutation logic
  are retained. `page_state.cpp` decreased from 12,606 to 12,522 lines.
- Original and extracted code compiled under C++20 with `-Wall -Wextra -Werror`,
  UBSan, and non-recovering diagnostics. **20,271 byte-input cases** produced
  identical parsed pairs, canonical serialization, reparsed pairs, and direct
  pair serialization. Every byte value 0–255 is covered, with no UBSan findings;
  seed `110483`.
- Added seven Python regression items. Focused query/URL collection: **54**;
  full collection: **1,808**. Local V8-free focused pytest: **4 passed,
  50 skipped**. Runtime skips do not verify the extracted native behavior.
- Scratch corpus, executables, and logs are under ignored
  `data/query-refactor/`; they are not committed.
